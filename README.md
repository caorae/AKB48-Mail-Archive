## 日本語

AKB48 Mail Archive は、AKB48 Mail のメールを自分の端末に保存するための非公式 Android バックアップ / オフライン閲覧ツールです。

新規バックアップは、AKB48 Mail のサービス提供中である **2026年11月30日（月）まで** に行う必要があります。

### 使い方

公式 AKB48 Mail アプリで「引き継ぎパスワード」を発行し、本アプリに引き継ぎIDと引き継ぎパスワードを入力してください。

その後、メール本文と画像を端末内へ保存します。

メール数や画像数が多い場合、すべてのダウンロードが完了するまで時間がかかることがあります。完了するまでアプリを終了せず、そのままお待ちください。

### 非公式について

本プロジェクトは非公式であり、AKB48、公式運営、および公式アプリの開発・運営元とは一切関係ありません。

ご自身が正当にアクセスできるアカウントのバックアップ用途にのみ使用してください。

保存したメール本文や画像についても、関連する利用規約および権利者のルールに従い、個人での閲覧・保管を目的として取り扱ってください。

## English

AKB48 Mail Archive is an unofficial Android backup and offline viewing tool for saving AKB48 Mail messages to your own device.

New backups using this tool must be completed while the AKB48 Mail service is still available, **before November 30, 2026**.

### How to use

Generate a transfer password (引き継ぎパスワード) in the official AKB48 Mail app, then enter your transfer ID and transfer password in this app.

The app will then save your mail content and images to your device.

If your account contains a large number of messages or images, the backup may take some time to complete. Please keep the app open until the download has finished.

### Unofficial project

This is an unofficial project and is not affiliated with AKB48, its official management, or the developers/operators of the official application.

Please use this tool only to back up an account that you are legitimately authorized to access.

Saved mail text and images should also be handled in accordance with the applicable terms of service and rights-holder rules, and should be used only for personal viewing and archival purposes.
